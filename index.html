วิธีเชื่อมต่อ Google Sheets

  1. สร้าง Google Sheets ใหม่
  2. ไปที่ Extensions → Apps Script
  3. วางโค้ด Apps Script (ปุ่มด้านล่าง) แล้วกด Save
  4. Deploy → New deployment → Web app
  5. ตั้ง "Who has access" เป็น Anyone
  6. คัดลอก URL มาใส่ในช่องด้านล่าง

ถ้าไม่ใส่ URL จะใช้โหมด Demo (บันทึกในเครื่อง)
